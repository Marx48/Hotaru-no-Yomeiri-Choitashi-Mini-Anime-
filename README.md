# 🏮 Hotaru no Yomeiri: Choitashi - English Subtitles

English subtitles (.ass) for the mini-anime series **Hotaru no Yomeiri: Choitashi** (ホタルの嫁入り ちょい足し).

## 📌 About the Project
This repository contains fan-made English translations and formatted subtitle files for the official short anime episodes of *Firefly Wedding* (Hotaru no Yomeiri). The timing, text formatting, and visual styles have been customized using **Aegisub**.
**Format:** SubStation Alpha (.ass) with full formatting tags, colors, and positioning.

## 🛠️ How to Use

1. Download the `.ass` or `.srt` subtitle file from the repository.
2. Place the downloaded subtitle file in the same folder as your video file.
3. Rename the subtitle file to match the exact name of the video file (e.g., Episode 01.mp4 and Episode 01.ass).
4. Play the video using a compatible media player such as **VLC**, **MPC-HC**, or **mpv**.
